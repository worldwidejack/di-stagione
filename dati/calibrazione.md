# Referto di calibrazione

Anni analizzati: [2024, 2025] — soglia: 50% degli anni.

La barra è l'anno, gennaio→dicembre. `█` quotato quasi sempre, 
`▓` spesso, `░` raramente, `·` mai (con origine italiana).
